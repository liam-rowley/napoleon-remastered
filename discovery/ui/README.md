# Vanilla UI atlas (J10)

Generated by `python3 core/wsc.py discovery render` from `summary.json` (written by `discovery/core/ui_atlas.py`). Do not edit.
Re-run: `python3 core/wsc.py discovery ui` on the PC (needs the extract, `discovery/README.md`); `wsc discovery check` checks the files.

## Files

- `<context>.json.gz` (battle, campaign, common, frontend, template): every layout and uied.templates record: components (path, rect, flags, states with art as `assets` ids, text and tooltip keys and lengths, fonts, transitions, animations), events with their handler and where it is defined, scripts attached, who opens it, templates used, frame groups. Loc text is never written, only keys.
- `scripts.json.gz`: the symbolic walk of every compiled UI script (`discovery/core/ui_walk.py`): engine calls, fields read off engine results, handlers, data passed in, panel ids.
- `summary.json`: counts and per unit the complexity record and hotkeys; `units.json.gz`: per unit the scripts, engine calls, interactions, unresolved fields with the reason, getters not in the state they run in.
- `registries/ui_elements.jsonl`: one row per pipeline unit at status `atlas`, generated from the same records.
